## ユーザー登録機能のテスト項目
### 基本動作
- [ ] ユーザー登録画面への遷移
- [ ] 成功時、ログインページに遷移
- [ ] 失敗時、ユーザー登録画面に留まる
### 正常系
- [ ] 全項目を正しく入力して登録
- [ ] 成功時のフラッシュメッセージ表示
- [ ] データベースに正しく保存されている
- [ ] パスワードが暗号化されている
### 異常系
- [ ] 全項目未入力
- [ ] メールアドレスのみ未入力
- [ ] ニックネームのみ未入力
- [ ] パスワードのみ未入力
- [ ] メールアドレスが既に登録済み
- [ ] メールアドレスの形式が不正
- [ ] パスワードとパスワード確認が不一致
- [ ] パスワードが最小文字数未満
- [ ] エラー時のフラッシュメッセージ表示
- [ ] エラー時に入力値が保持されている（パスワード以外）
### UI・UX(スマホ使用を念頭におく)
- [ ] 画面レイアウトが崩れていない
- [ ] 入力フォームがタップしやすい
- [ ] メールアドレス入力時に適切なキーボードが表示
- [ ] パスワード入力時に文字が隠れる

### 基本動作
- [ ] ホーム画面への遷移
- [ ] 成功時、ホーム画面にリダイレクト
### 正常系
- [ ] 当日の記録がない場合、記録フォームが表示される

- [ ] 5段階の評価をそれぞれ記録できる
- [ ] 成功時のフラッシュメッセージ表示
- [ ] 記録後、記録した気分が正しく表示される
- [ ] 記録後、記録ボタンが非表示または無効化される
- [ ] 当日の記録がある場合、記録済みの表示（例：GOOD）がされる
- [ ] 当日の記録がある場合、記録ができないようになっている
- [ ] 翌日になると再度記録できるようになる
### データベース
- [ ] データベースに正しく保存されている
- [ ] 記録した日付が正しく保存されている
- [ ] 記録した気分の評価値が正しく保存されている
- [ ] ユーザーIDが正しく紐付けられている
### 異常系
- [ ] 既に当日の記録がある状態で、URLを直接叩いての記録
- [ ] 不正なパラメータ（範囲外の評価値など）を送信した場合、エラー処理がされる
- [ ] ボタンの連打による二重送信が防止されている
### UI・UX(スマホ使用を念頭におく)
- [ ] 画面レイアウトが崩れていない
- [ ] 各評価ボタンに適切なラベルや説明が表示されている
- [ ] 評価ボタンがタップしやすいサイズになっている
- [ ] ボタン間の余白が十分にある
- [ ] 誤タップしにくいレイアウトになっている
- [ ] 画面をスクロールせずに主要な情報が見える
- [ ] フラッシュメッセージがスマホ画面で適切に表示される

## 閲覧機能(ホーム画面)のテスト項目
### 基本動作
- [ ] ホーム画面への遷移
- [ ] 初回アクセス時、今月の記録が表示される
- [ ] 初回アクセス時、今月の年月が検索フォームに表示されている
- [ ] 記録が日付の昇順（古い順）で表示される
- [ ] 記録がない場合は何も表示されない
- [ ] 1か月単位で記録を検索可能
- [ ] スクロールは記録の表示部分のみになっている（ヘッダーは常に画面に表示される）
### 正常系
- [ ] 5段階全ての評価が正しく表示される
- [ ] 各評価に対応するアイコンや色が正しく表示される
- [ ] 日付が適切な形式で表示される
- [ ] 月を変更して検索すると、該当月のデータのみが表示される
- [ ] 検索した月のデータのみが表示される（他の月のデータが混じっていない）
### データベース
- [ ] データベースに保存されている気分の評価値が正しく表示される
- [ ] データベースに保存されている日付が正しく表示される
- [ ] 表示件数がデータベースの該当月の記録件数と一致する
- [ ] ログインユーザー自身の記録のみが表示される
### 異常系
- [ ] 他のユーザーの記録を直接URL指定で閲覧できないことを確認
- [ ] 不正な月（13月、0月など）を指定できない
- [ ] 不正な年（負の数、文字列など）を指定できない
- [ ] 未来の月を検索した場合、適切に処理される（エラーまたは空の結果）
- [ ] ブラウザの戻るボタンでの挙動
- [ ] ページをリロードし場合どうなるか
### UI・UX(スマホ使用を念頭におく)
- [ ] 画面レイアウトが崩れていない
- [ ] 記録日と記録値が認識しやすい
- [ ] 各記録が区切られて表示される（カードやリストアイテムとして）
- [ ] 記録がない日と記録がある日が区別しやすい
- [ ] スクロールがスムーズ
- [ ] 記録の推移が視覚的に分かりやすい（グラフがあれば確認）
### パフォーマンス
- [ ] 記録が多い月でも表示が遅くならない
- [ ] 月の切り替えがスムーズ

## 編集機能(編集画面)のテスト項目
### 基本動作
- [ ] ホーム画面から編集ボタンをクリックして編集画面に遷移できる
- [ ] 編集画面のURLに記録のIDが含まれている
- [ ] 編集画面を開いた時、現在の評価値が選択された状態で表示される
- [ ] 編集画面を開いた時、記録日が表示される
- [ ] 更新後、ホーム画面にリダイレクト
- [ ] 更新失敗時、記録編集画面に留まる
### 正常系
- [ ] 5段階の評価それぞれに変更できる
- [ ] 同じ評価値を選択し直すこともできる（変更なしでも更新可能）
- [ ] 更新ボタンをクリックすると、記録が更新される
- [ ] 成功時のフラッシュメッセージ表示
- [ ] ホーム画面で更新後の評価値が正しく表示される
- [ ] 記録日は変更されない
### データベース
- [ ] データベース上で該当の記録が更新されている（新規作成されていない）
- [ ] 記録のIDが変わっていない
- [ ] 記録した気分の評価値が正しく保存されている
- [ ] 記録した日付が正しく保存されている（変更されていない）
- [ ] ユーザーIDが変わっていない
- [ ] 更新日時（updated_at）が更新されている
- [ ] 作成日時（created_at）が変わっていない
- [ ] 他の記録に影響を与えていない
### 異常系
- [ ] 存在しない記録IDで編集画面にアクセスした場合、404エラーまたはホーム画面へ
- [ ] 不正なパラメータ（範囲外の評価値など）を送信した場合、エラー処理される
- [ ] 評価値を選択せずに更新ボタンをクリックした場合、適切にエラー処理される
- [ ] ボタンの連打による二重送信が防止されている
- [ ] 編集画面でページをリロードしても、編集中の記録が正しく表示される
- [ ] 失敗時、フラッシュメッセージ表示
- [ ] 更新失敗時、入力した評価値が保持される（再入力の手間を省く）
### UI・UX(スマホ使用を念頭におく)
- [ ] 画面レイアウトが崩れていない
- [ ] 編集画面であることが分かる見出しやタイトルが表示されている
- [ ] 現在編集中の記録日が明確に表示されている
- [ ] 現在の評価値がどれか一目で分かる
- [ ] 各評価ボタンに適切なラベルや説明が表示されている
- [ ] 評価ボタンがタップしやすいサイズになっている
- [ ] ボタン間の余白が十分にある
- [ ] 誤タップしにくいレイアウトになっている
- [ ] 更新ボタンとキャンセルボタンが区別しやすい
- [ ] 更新ボタンが目立つ位置・デザインになっている
- [ ] フラッシュメッセージがスマホ画面で適切に表示される
